# 各平台发布机制全解（登录 → 编辑器 → 发布 → 更新）

> 说明：本文档基于 `core/adapters/` 下 9 个适配器的**真实实现**整理（2026-09 实测过的选择器与接口），
> 不是设计稿。每个平台的"接入方式 / 建稿 / 编辑器 / 特有字段 / 发布 / 更新 / 坑"都是代码里实际在跑的逻辑。

---

## 一、总览：三种接入方式

| 方式 | 平台 | 特点 | 登录方式 |
|---|---|---|---|
| **纯 API**（不开浏览器） | 博客园、自建博客 | 用户名+令牌/密码，XML-RPC 直发 | 配置一次，免扫码 |
| **站内 API + 页面上下文 fetch** | 掘金、思否、B站 | 用浏览器 cookie 调平台内部接口建稿，比 UI 稳 | 扫码/账密一次 |
| **浏览器 UI 注入** | CSDN、知乎、头条、开源中国 | 打开写作页，真实操作编辑器 | 扫码/账密一次 |

## 二、逐个平台拆解

### 1. 掘金 juejin —— "API 建稿 + UI 面板发布"（重点：分类和标签）

```
登录态 → user/get 拿 user_id → 走 content_api 建草稿 → 进编辑器点「发布」→ 面板点「确定并发布」→ 轮询 URL 是否跳 /post/xxx
```

| 环节 | 实际做法 |
|---|---|
| **分类** | 必须选。`CATEGORIES` 表映射 8 类（前端/后端/android/ios/人工智能/开发工具/代码人生/阅读），默认"后端"。前端没传时用默认 |
| **标签** | 必须至少一个。**已修复**：文章 tags 第一个词 → `KNOWN_TAG_IDS` 兜底表（Python=7104、Go=7097、JavaScript=7003…15 个常用标签）→ 在线 `query_tag_list` 搜索 → 全失败兜底 Python |
| 摘要 | `brief_content`，取文章 summary，没有则截正文前 100 字 |
| 封面 | `cover_image`，取文章 cover 字段（一般没有就是空） |
| 正文 | `mark_content` 直接传 Markdown（`edit_type=10`） |
| 专栏/活动 | `column_ids` / `theme_ids` 传空数组——**可选字段，不填不影响发布** |

**发布有个大坑（2026-09 实测）**：官方 `article/publish` API 已封死，只能走 UI 面板。
点「确定并发布」后掘金前端只发 `article_draft/update`，如果 URL 没跳到 `/post/xxx` 说明没发出去——
代码会返回"草稿已建 + 请手动点确定并发布"的警告（记 `pending_human`，前端"需要人工"页能看到）。
这不是 bug，是平台改版后的兜底策略。

更新：进编辑页 → 改标题（Ctrl+A + 真实击键）→ 注入正文 → 点「发布/确定并发布」。

### 2. CSDN —— "浏览器 UI 注入 + 发布弹窗三件套"（最复杂的编辑器）

```
登录态 → 写作页 → 【先导正文】→【再设标题】→ 点发布 → 弹窗填【分类专栏+摘要+标签】→ 点发布 → 轮询跳转 success 页
```

| 环节 | 实际做法与血泪坑 |
|---|---|
| **正文** | **必须先导**：用隐藏的 `input[type=file][accept=.md]` 注入 Markdown 文件（代码块/表格渲染最稳），失败降级逐字输入。**顺序反了会出大事故**：先设标题再导入，标题会被重置成草稿临时名 `tmpXXXXXXXX` |
| **标题** | 编辑器标题框是 `display:none` 的隐藏 input，JS setter 写不进去（框架状态不同步）。唯一可靠路径：**强制显示 → 原生 click → 真实击键**，再拿 display 区域校验，不一致直接中止发布（防止产生 tmp 标题废文） |
| **分类专栏** | 弹窗里必填，默认"后端与架构设计"（`options.category` 可改） |
| **摘要** | 弹窗里强烈建议填（不填 CSDN 截正文前 256 字）。取文章 summary，没有用标题 |
| **标签** | 弹窗里"添加文章标签"面板选一个（**已修复**：优先匹配文章第一个标签，否则点第一个推荐标签）。**选完绝不点任何 close 按钮**——DOM 里第一个 close 是关闭整个弹窗，点了=发布按钮没了 |
| **今日额度** | 发布弹窗自带额度提示，0 篇直接报错，不白等 40 秒 |
| 验证码 | 发布链路里检测到验证码 → 明确报类型交人工 |

发布按钮用 JS click（原生 click 被 fixed 弹窗的浮层拦截超时）。成功后轮询跳转 `creation/success/{id}`；
失败前按标题查列表对账一次（文章可能实际已发出，防重复发浪费每日额度）。
更新：进编辑页 → 注入正文 → 点发布 → **轮询等弹窗关闭**（30s 不关报错）。

### 3. 知乎 zhihu —— "Markdown 文件导入 + 点发布"（Draft.js 编辑器）

```
写作页 → 填标题 → 点「导入」→ 点「导入文档」→ 点上传区（捕获 filechooser）→ 注入 .md → 点发布 → 轮询跳 /p/xxx
```

| 环节 | 实际做法 |
|---|---|
| 标题 | 限 100 字，`textarea.Input` |
| 正文 | 知乎是 Draft.js，**ClipboardEvent 粘贴已失效**。唯一稳的路：工具栏「导入」→「导入文档」modal → 上传区 `div[role=button]` + `expect_file_chooser` 捕获 → `set_files(.md)`。降级逐字输入 |
| 草稿 | 编辑器自动存草稿但**没有公开草稿 ID**，draft_only 就是"不点发布"交人工 |
| 发布 | 点「发布」→ 首次会弹开通/话题选择 → 再点「确认」→ 轮询 URL 是否跳 `/p/<id>`。30s 不跳 → 报错让用户手动确认后用「原地更新」补状态 |
| 更新 | 打开文章 → 点「编辑」→ 改标题+重导入 → 点「保存并发布」（已发布）或「发布」（草稿） |

### 4. 头条号 toutiao —— "UI 注入 + 两次发布"（标题限 30 字）

```
发布页 → 填标题(30字) → HTML 粘贴进 contenteditable → 点 publish-btn → 预览页再点一次发布 → 部分弹窗交人工
```

- 标题 `textarea` 限 **30 字**，超了直接截断（代码里 `[:30]`）
- 正文自研富文本编辑器，`contenteditable` HTML 粘贴
- 编辑器**自动存草稿**，draft_only 就是不发
- 发布要点两次：`publish-btn` → 预览/确认弹层里再点一次
- **不支持原地更新**（删除重发）
- 未登录访问会跳 `sso.toutiao.com`（登录态判定依据）

### 5. 开源中国 oschina —— "UEditor iframe 富文本"

```
写作页 → 填标题 → HTML 粘贴进【iframe 里的 UEditor】→ 点发布 → 弹设置弹层（分类/摘要）尽量确认
```

- 编辑器在 **iframe** 里，得进 frame 找 `contenteditable body` 粘贴 HTML
- 发布后弹的分类/摘要设置弹层：依次试「确定/发布/确认」，点到为止
- **不支持原地更新**
- 登录态判定：首页右上角"登录/注册"链接消失

### 6. 思否 segmentfault —— "API 建草稿 + UI 发布"

```
gateway/draft API 建稿（PHPSESSID 当 token）→ 打开草稿页（CodeMirror）→ 点发布 → 弹确认尽量点
```

- 建稿/更新都走 `POST /gateway/draft`，`PHPSESSID` cookie 当 token
- 标签：**已修复**——原来传空数组，现在传文章 tags
- 发布：写作页点「发布」→ 弹的分类/标签确认弹层依次试「确定/确认发布/发布」
- post_url 用草稿 ID 兜底（`/a/{id}`）

### 7. B站专栏 bilibili —— "创作 API 只到草稿"（特殊：不能自动公开发表）

```
nav 接口验登录态 → /x/article/creative/draft/addupdate 建草稿（FormData + bili_jct csrf）→ 只到草稿，人工发表
```

- 标题限 **40 字**，超了接口直接拒（`[:40]`）
- summary 必填（取文章 summary 或正文前 100 字），`original=1` 原创标记
- 标签：**已修复**——原来传空，现在传文章 tags（逗号拼接）
- **正式发表必须人工二次选分区**：B站 API 直接发表会被拒（缺分区信息），代码老老实实交付草稿箱+编辑页链接，不做假成功
- 更新：API 原地更新草稿

### 8. 博客园 cnblogs —— "纯 XML-RPC"（唯一第三方免扫码）

```
config.json 填 endpoint/username/token → blogger.getUsersBlogs 验 → metaWeblog.newPost 发 → editPost 更新
```

- **2026-06 起取消密码登录**，必须用「MetaWeblog 访问令牌」；`cli.py bootstrap-cnblogs` 浏览器自动抠
- 正文传 Markdown 原文，categories 必须带 `[Markdown]` 标记（否则当 HTML 渲染）
- `draft_only` 控制是否公开
- 更新是全额覆盖（editPost 天然原地更新）
- 免浏览器、零验证码，一次配置长期有效

### 9. 自建博客 metaweblog —— "通用 XML-RPC"（新增）

```
config.json 填 endpoint/username/password → getUsersBlogs 验 → newPost 发 → editPost 更新
```

- WordPress 用「应用程序密码」（用户→个人资料→应用程序密码生成），Typecho 用登录密码
- 正文直接传 Markdown 原文（Typecho 原生渲染；WordPress 需装 Markdown 插件）
- 标签走 `mt_keywords`
- 完全免浏览器免扫码

## 三、平台特有字段速查表（发布时每个平台要注意什么）

| 平台 | 标题上限 | 标签 | 分类/专栏 | 活动 | 摘要 | 封面 | 原地更新 |
|---|---|---|---|---|---|---|---|
| 掘金 | — | ✅ 必须≥1（文章 tags→ID） | ✅ 必选分类（默认后端） | 可选(空) | ✅ 自动 | 可选(空) | ✅ |
| CSDN | — | ✅ 弹窗选≥1（文章首个tag） | ✅ 必填分类专栏（默认后端与架构） | — | ✅ 建议填 | — | ✅ |
| 知乎 | 100 | — | 发布时可选话题 | — | — | — | ✅ |
| 头条 | **30** | 编辑器里手填 | 可选 | — | — | 编辑器里手填 | ❌ |
| 开源中国 | — | — | 弹层选 | — | 弹层填 | — | ❌ |
| 思否 | — | ✅ 文章 tags | 可选 | — | ✅ cover 字段 | ✅ cover | ✅ |
| B站 | **40** | ✅ 文章 tags | ❌ 必人工选分区(发表时) | — | ✅ 必填 | ✅ banner | ✅(草稿) |
| 博客园 | — | ✅ categories+[Markdown] | 可传 | — | — | — | ✅ |
| 自建博客 | — | ✅ mt_keywords | — | — | — | — | ✅ |

**一句话总结每个平台的"最后一步"**：
- 掘金/CSDN/知乎/思否/头条/开源中国：自动点到底，失败会明确报"哪个弹窗没确认"并给编辑页链接
- **B站：只能到草稿，发表必须人工选分区（平台硬性要求，不做假成功）**
- 博客园/自建博客：全自动直发
